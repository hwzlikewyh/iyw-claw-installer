# 安装向导实现与验收

日期：2026-11-09。目标是轻量、有设计感、流畅的原助理原生安装器。
当前行为以用户最后要求为准：真实 Fusion 稳定版、允许回退、已安装健康组件复用、
主包及后台预置环境完整准备、低资源的受控并发、成功后启动软件。

## 界面

960×640 原生深色窗口，原助理品牌图形、轨道、平滑浮动和指针跟随。
基础布局来自 design-taste-frontend 的 true-black-flat 方向（seed 776806633）；
用户要求进一步炫酷后，品牌画面增加蓝色光照及轨道，不把这些效果扩展到信息区。
保持高对比文字，进度反映真实工作量；未知工作量显示等待条，不伪造整体百分比。

参考了 nsNiuniuSkin 的实际安装截图和 Flow Launcher 欢迎页；使用原助理本身的素材。
用户否定的白底左栏布局已替换；“安装说明”按钮、说明弹窗和安装进行中的阻塞提示已删除。
路径栏统一背景、内边距和悬停状态；页面位移动画扩大脏区，消除右侧残影。

## 下载、环境及复用

版本查询使用 Fusion `check/{target}/{arch}/0.0.0`，stable/manual，带有效安装 ID 与防缓存参数。
不比较本机版本高低；同版本且签名有效时复用。下载后版本一致性仍检查，防止误启动旧文件。

主包最多 3 路分段，Range 响应及区间校验后落盘；不支持 Range 时顺序读取。
预置环境计划使用空库存查询服务器的初始化默认集合，固定上下文为应用版本/平台/架构。
计划对照后台 installOnInitialize 策略；执行前通过版本、制品 ID、制品摘要身份、目录和入口大小
做轻量检查，已安装健康项从待下载队列移除。

缺失环境最多 2 路下载，校验后进入 `.iyw-claw/runtime/cache/downloads/<sha256>/artifact`，
保持与环境助手缓存契约一致。校验和解包串行；明确组件选择可避免助手再次按浏览器偏好删减。
修复后逐项比对完整预置集合；助手吞掉可选组件失败时，向导仍会报告剩余缺项，不报全部完成。
后台当前关闭的 BGE Small 初始化下载不恢复。

主包先于预置环境下载，不叠加并发。原生 I/O 固定缓冲，状态限频；Windows 后台任务优先级较低。
安装已有组件不计算全部文件摘要，保持现有普通安装的轻量语义；修复时才进行全量诊断。

## 平台及验证范围

Windows 使用正式 NSIS 事务，/S /UPDATE /D=，参数不通过 shell；保留安装器权限、WebView2、
环境和回滚。只有子进程成功、应用/助手存在、版本及签名通过且预置集合完整，才能启动。
Win32 引导入口同时可用于 32/64 位 Windows；精确系统与架构决定实际包。
新版静态 C++ 时钟的 Win10 导入已改成运行时解析，Win7 回退到已有 FILETIME 接口。

macOS/Linux 已接入 libcurl、固定公钥的 minisign 验签、应用部署与旧 app 备份恢复。
macOS 检查 codesign、标识和版本；Linux 从验签后的 AppImage 解包，不依赖 FUSE。
调用相同的受管环境助手；系统图形库缺失明确给出包名，未自动改动系统包管理器。

没有在本机进行 Win7、macOS 或 Linux 运行验收。Linux 使用真实 Debian 目标头文件做了
编译语法检查；不能将它等同于原生链接和运行。未上传或发布，也未修改后端数据库或安装策略。
后端数据库直连凭据不可用，已通过同一数据库驱动的只读管理 API 核对安装策略，并以公开计划验证实际结果。

相邻应用助手只改了移除 Open Computer Use 无条件过滤的两行，遵循其本机不编译、不运行测试的规则，
完成 Rust 语法解析和差异检查。新行为仍需随新版应用发布；旧已发布 helper 不会因向导更新自动改变。

## 安装期间文字轮播（2026-11-09）

用户要求增加安装时的句子轮播和动效。保持现有双栏、深色与蓝色品牌布局，
在左侧品牌图下方展示 4 组产品使用短句；右侧仍显示真实步骤、下载量、速度及错误。
轮播周期 4.5 秒，过渡 0.6 秒，先淡出再淡入，轻微向上位移；不同时叠画两组文字。
当前步骤增加呼吸提示，未知进度指示平滑往返。完成立即切换结果，不为展示动效延迟安装。

复用既有动画计时器，扩大左下方局部刷新区域。最小化暂停，Windows 关闭客户端动画时
固定第一句，每次重新安装重置。只改私有界面代码，不修改安装状态、后端协议或依赖。

验收：Release 编译、安装中三次短句切换及循环、过渡帧无重叠和裁切、关闭动画静态比对、
最小化资源检查、实际同版复用到完成。完整记录见 verification.md；演示为 install-motion.gif。

经验：wxWidgets 3.2 的 Windows GDI+ 后端 BeginLayer/EndLayer 未实现，不能靠整层透明度
实现文本淡化；文字淡化使用 wxColour alpha，并在原生窗口逐帧检查。
