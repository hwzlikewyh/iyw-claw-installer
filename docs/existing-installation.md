# 启动时识别已有 Windows 安装

0.2.11 在创建安装界面时读取当前用户和所有用户的 64/32 位产品记录、默认值与卸载记录，只接受实际存在 app/iyw-claw.exe 的目录。旧记录指向 app 时转换回父目录，失效记录不会挡住下一条有效记录。

找到已有安装后，直接显示更新设置、版本和原路径。选择其他目录时重新检查；点击继续时再次归一化 app 路径，避免部署到 app/app。没有已有安装时维持首次安装流程。相同稳定版仍沿用现有签名与组件复用检查。

验证使用 scripts/tests/existing_install.cpp，在单独进程中把 HKCU/HKLM 重定向到测试专用注册表树，覆盖首次安装、机器级安装、过期记录、默认记录、中文空格路径与旧 app 目录，结束时恢复映射并删除测试数据。本机验证不能代替 Win7 真机升级。
