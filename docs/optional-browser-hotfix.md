## 0.2.6 更新预准备收尾

正常的 Windows x64 直接载荷更新在父应用退出前完成应用解包校验、WebView2 检查补装、
环境助手 prepare。退出后激活本地应用与已准备环境，并自动重新打开应用。
准备阶段不写全局安装事务；同版本复用不读取不存在的应用 ZIP。
旧事务尚未完成时暂缓本次 prepare，握手后先恢复旧事务，避免覆盖恢复依据。
旧 NSIS 保留兼容路径，受保护目录沿用 Windows 权限助手。

验证：五项流程检查通过（正常预准备、同版本复用、中断恢复、准备失败保留旧应用、
NSIS 兼容）；二十九项真实 ZIP/发布签名/隔离文件事务检查通过。
这些检查使用隔离目录及模拟助手，不等同于真实机器上的全流程升级或保证秒级耗时。
